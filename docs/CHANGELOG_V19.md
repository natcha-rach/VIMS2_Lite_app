# V19 — หน้าร้าน (POS) · รอบเปิดร้าน · จอง · สรุปภาษี

## ขั้นตอนอัปเกรด (ทำตามลำดับ)

1. Supabase → SQL Editor → รัน `sql/migration_v19_pos_shift.sql` (รันซ้ำได้ ไม่ลบข้อมูลเดิม) — โปรเจกต์ใหม่: รัน `schema_part1-3` ก่อนแล้วตามด้วยไฟล์นี้
2. อัปโหลดไฟล์เว็บทั้งหมดขึ้น hosting ทับของเดิม
3. เปิดหน้า "ขายของ" → ปุ่มเฟือง → ใส่เบอร์พร้อมเพย์ + ชื่อร้านบนใบเสร็จ
4. (แนะนำ) ล็อกฐานข้อมูลให้ต้อง Login: ทำตามหัวไฟล์ `sql/migration_v20_auth_lock.sql`
5. (แนะนำ) สำรองข้อมูลทุกคืน: ตั้งค่า secret ตามหัวไฟล์ `.github/workflows/backup.yml`

# V19.2 — แก้บั๊ก Realtime บนมือถือ

- อาการ: เปิดบนมือถือขึ้น "cannot add `postgres_changes` callbacks for realtime:vims2-lite-realtime after `subscribe()`"
- สาเหตุ: `realtime.js` เรียก subscribe ซ้ำตอนเปิดหน้า และตอนเชื่อมต่อหลุด (เช่น สลับแอป/จอดับ) ไม่ได้ลบ channel เดิมก่อนต่อใหม่
- แก้: กันเชื่อมซ้ำ, ลบ channel เก่าทุกครั้ง, ตั้งชื่อ channel ใหม่ทุกรอบ, ห่อ try/catch, ต่อใหม่เมื่อกลับมาที่หน้า (หน่วงเวลาเพิ่มขึ้นเรื่อยๆ สูงสุด 30 วิ)
- ทดสอบกับ supabase-js ตัวจริง: เวอร์ชันเก่า error ซ้ำ 2 ครั้ง / เวอร์ชันใหม่ไม่มี error
