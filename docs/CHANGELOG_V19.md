# V19 — หน้าร้าน (POS) · กะขาย · จอง · สรุปภาษี

## ขั้นตอนอัปเกรด (ทำตามลำดับ)

1. Supabase → SQL Editor → รัน `sql/migration_v19_pos_shift.sql` (รันซ้ำได้ ไม่ลบข้อมูลเดิม) — โปรเจกต์ใหม่: รัน `schema_part1-3` ก่อนแล้วตามด้วยไฟล์นี้
2. อัปโหลดไฟล์เว็บทั้งหมดขึ้น hosting ทับของเดิม
3. เปิดหน้า "ขายของ" → ปุ่มเฟือง → ใส่เบอร์พร้อมเพย์ + ชื่อร้านบนใบเสร็จ
4. (แนะนำ) ล็อกฐานข้อมูลให้ต้อง Login: ทำตามหัวไฟล์ `sql/migration_v20_auth_lock.sql`
5. (แนะนำ) สำรองข้อมูลทุกคืน: ตั้งค่า secret ตามหัวไฟล์ `.github/workflows/backup.yml`

## ฐานข้อมูลที่เพิ่ม

- ตารางใหม่: `shifts`, `bills`, `reservations`
- คอลัมน์ใหม่: `sales.bill_id`, `sales.list_price`, `expenses.shift_id`, `expenses.paid_from`, `item_images.thumb_url`, `item_images.thumb_path`
- index: `idx_items_sellable` (partial: ของที่ยังขายได้) — ไม่ต้อง archive ของที่ขายแล้ว
- RPC: `sell_bill`, `void_bill`, `void_sale` (อัปเดต), `open_shift`, `shift_totals`, `close_shift`, `reserve_item`, `release_reservation`, `storage_usage`
- `sell_item` เดิมยังอยู่ (ไม่มีหน้าไหนเรียกแล้ว)
