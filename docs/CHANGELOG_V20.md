# V20 — ขายตอนเน็ตหลุด · ประวัติรอบร้าน · อะไรขายดี · ลดราคาของค้าง · ลดพื้นที่รูป · รายการจอง

## ขั้นตอนอัปเกรด (ทำตามลำดับ)

1. Supabase → SQL Editor → รัน `sql/migration_v21_offline_markdown.sql` (รันซ้ำได้ · ต้องรัน v19 มาก่อน)
2. `git push` เข้า `master` → Cloudflare Pages deploy ให้เอง
3. (ครั้งเดียว) Cloudflare Pages → Settings → Build: **Build command** `sh scripts/build-site.sh` · **Build output directory** `dist`
   → เว็บจะไม่เปิดให้เห็นไฟล์ `sql/ tests/ docs/`
4. (ครั้งเดียว) GitHub repo → Settings → Secrets → Actions: เพิ่ม `SUPABASE_DB_URL` ให้ backup ทุกคืนทำงาน

ถ้า push ก่อนรัน SQL: หน้าเว็บยังใช้ได้ — บิลที่ขายตอนเน็ตหลุดจะส่งโดยไม่มีเวลาขายจริง, ปุ่มลดราคาของค้างและลบรูปเต็มจะแจ้งให้รัน SQL ก่อน

## สิ่งที่เปลี่ยน

| ส่วน | ไฟล์ | รายละเอียด |
| --- | --- | --- |
| ขายตอนเน็ตหลุด | `assets/js/offline.js`, `sell.js`, `sw.js` | ส่ง `sell_bill` ไม่ได้เพราะเน็ต → เก็บบิลใน IndexedDB ขายลูกค้าคนต่อไปได้ทันที, ป้าย "รอส่ง N บิล", ส่งเองเมื่อเน็ตกลับ/ทุก 30 วิ ด้วย UUID เดิม (ไม่เกิดบิลซ้ำ), บิลที่ส่งไม่ผ่าน (เช่น ของถูกขายไปแล้ว) ให้ลองใหม่/ทิ้งพร้อมเหตุผล, กริดสินค้าชุดล่าสุดเก็บในเครื่อง, `sw.js` ให้เปิดหน้าเว็บได้ตอนไม่มีเน็ต |
| เวลาขายจริง | RPC `sell_bill(…, p_sold_at)` | บิลที่ส่งทีหลังได้เวลาขายจริง · ผูกรอบร้านเฉพาะรอบที่เปิดก่อนเวลาขาย · ย้อนได้ไม่เกิน 7 วัน |
| กันปิดร้านพลาด | `shift.js` | ยังมีบิลรอส่งในเครื่อง → ปิดร้านไม่ได้ |
| ประวัติรอบร้าน | `assets/js/shift-history.js` (หน้าบัญชี) | สรุปตามทำเล (ขาย/กำไร/ชิ้นต่อรอบ, ขายต่อชั่วโมง, ขาด-เกินรวม) + รายการรอบร้านกดดูรายละเอียด |
| เงินจริงในหน้าบัญชี | `accounting.js` | รวมเงินขาด/เกินตอนปิดร้าน (`shifts.cash_diff`) เข้า "เงินสด + เงินโอน ที่มีจริงตอนนี้" |
| อะไรขายดี | `assets/js/insights.js` (หน้ารายงาน) | แยกตามไซซ์/สภาพ/ประเภท/Tier/ช่วงราคา: ขายแล้ว, ขายเฉลี่ย, กำไรเฉลี่ย, กี่วันขายออก (มัธยฐาน), ค้างอยู่, % ขายออก + Lot คืนทุนกี่วัน |
| ลดราคาของค้าง | `assets/js/stale.js` (หน้าสต็อก), RPC `markdown_items` | ของค้าง 60/90/120+ วัน เลือกทั้งกองหรือรายชิ้น → ลด 10/20/30% หรือตั้งราคา, เตือนชิ้นที่ต่ำกว่าทุน, เก็บประวัติราคา |
| ลดพื้นที่รูป | `assets/js/storage-tools.js` (หน้าบัญชี) | สร้างรูปย่อให้รูปเก่า · ลบรูปเต็มของที่ขายเกิน 6 เดือน (เหลือรูปย่อ, จด `item_images.full_removed_at`) — ทำเมื่อกดเองเท่านั้น |
| รายการจอง | แท็บ "จอง" หน้าขาย | เรียงตามวันนัด, เลยนัดขึ้นสีแดง + เตือนตอนเปิดหน้าขาย, ปุ่ม "ขายเลย" / "ยกเลิกจอง" |
| CI | `.github/workflows/ci.yml`, `scripts/build-site.sh` | รัน unit test ทุก push · ลบ `pages.yml` (ใช้ Cloudflare แทน GitHub Pages) |

- `cd tests/ui && node run.js` — เพิ่ม: เน็ตหลุดตอนขาย → เข้าคิว → ส่งสำเร็จ, แท็บจอง, ลดราคาของค้าง, ประวัติรอบร้าน, การ์ดอะไรขายดี
